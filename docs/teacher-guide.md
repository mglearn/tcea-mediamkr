# TCEA MediaMkr — Teacher Guide

TCEA MediaMkr is built for classrooms. These notes help you use the tools with
students safely and effectively.

## Privacy with students

- The tools require **no student accounts** and collect **no student data**.
- Files are processed in the browser; nothing is uploaded by the tools.
- Students can work on shared or personal devices without signing in.
- When sharing a tool link, you can share the tool itself — not any student work
  — because work stays on the student's device until they export it.

## Classroom ideas

- **CodeMkr** — post QR codes that link to a reading, a form, or a station.
- **PuzzleMkr** — turn a diagram or image into a reveal puzzle for review.
- **PlotMkr** — have students graph data from an experiment or survey.
- **MemeMkr** — create captioned images for vocabulary or concept checks.
- **PixelMkr / BGMkr** — prepare clean images for slides and projects.
- **ClipMkr / AudioMkr** — record short explainer videos or podcasts.
- **GIFMkr** — animate a process in a few frames.
- **FormatMkr / DocMkr** — get media and PDFs ready to share.

## Accessibility

All tools target WCAG 2.2 AA. Encourage keyboard navigation and use the
accessible alternatives (such as PlotMkr's data tables) with students who use
assistive technology. See [`../ACCESSIBILITY.md`](../ACCESSIBILITY.md).

## Device tips

- Media tools (video, audio, conversion) work best on a laptop or desktop.
- Lighter tools (QR, memes, charts, puzzles) work well on tablets and
  Chromebooks.
