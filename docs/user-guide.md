# TCEA MediaMkr — User Guide

Welcome! TCEA MediaMkr is a set of free tools you use right in your web browser.
There is nothing to install and no account to create.

## Getting started

1. Open the [MediaMkr home page](../index.html).
2. Browse the tools or use the **search box** and **category filters** to find
   one.
3. Click **Open Tool**.
4. Add your own files. Your work is processed in your browser.
5. **Export** or **download** the finished file to share with students.

## Switching language

Use the **Language** menu in the top-right corner to switch between English and
Spanish. Your choice is remembered on your device.

## The tools at a glance

- **ClipMkr** — make and edit videos.
- **AudioMkr** — record and edit audio.
- **FormatMkr** — convert and prepare media files.
- **PixelMkr** — edit and create images.
- **BGMkr** — remove or replace image backgrounds.
- **PuzzleMkr** — build interactive image puzzles.
- **CodeMkr** — generate QR codes.
- **MemeMkr** — create captioned images.
- **GIFMkr** — make animated GIFs.
- **PlotMkr** — create charts and graphs.
- **DocMkr** — merge, split, and prepare PDFs.

## Need help?

Each tool includes in-app guidance. For more, visit [TCEA.org](https://tcea.org/).
