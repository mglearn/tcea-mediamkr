# TCEA MediaMkr — Source & License Audit

## Provenance

TCEA MediaMkr is adapted from the maintainer's own prior open-source tools. The
maintainer (Miguel Guhlin) holds the copyright on that original code and
relicenses it here under **AGPL-3.0-or-later** with TCEA MediaMkr branding.

Because the maintainer is the author of the adapted code, rebranding the user
interface does not remove anyone else's required attribution. The obligation to
preserve notices applies to **third-party** libraries and models bundled with
the tools, which is tracked in [`../THIRD_PARTY_LICENSES.md`](../THIRD_PARTY_LICENSES.md).

## Audit checklist (per tool)

For each tool, record before publishing:

1. Applicable license of the adapted code (AGPL-3.0-or-later unless noted).
2. Third-party dependencies and their licenses.
3. Required copyright notices preserved.
4. Required license texts preserved.
5. Modifications made.
6. Corresponding-source availability (this public repository).
7. License compatibility confirmed.
