# TCEA MediaMkr — User Guide

Welcome! TCEA MediaMkr is a set of free tools you use right in your web browser.
There is nothing to install and no account to create.

## Getting started

1. Open the [MediaMkr home page](../index.html).
2. Browse the tools or use the **search box** and **category filters** to find
   one.
3. Click **Open Tool**.
4. Add your own files. Your work is processed in your browser.
5. **Export** or **download** the finished file to share with students.

## Switching language

Use the **Language** menu in the top-right corner to switch between English and
Spanish. Your choice is remembered on your device.

## The tools at a glance

- **ClipMkr** — make and edit videos.
- **AudioMkr** — record and edit audio.
- **FormatMkr** — convert and prepare media files.
- **PixelMkr** — edit and create images.
- **BGMkr** — remove or replace image backgrounds.
- **PuzzleMkr** — build interactive image puzzles.
- **CodeMkr** — generate QR codes.
- **MemeMkr** — create captioned images.
- **GIFMkr** — make animated GIFs.
- **PlotMkr** — create charts and graphs.
- **DocMkr** — merge, split, prepare PDFs, and draw clickable link areas.

## Need help?

Each tool includes in-app guidance. For more, visit [TCEA.org](https://tcea.org/).

## Add clickable areas in DocMkr

Open a PDF or image, choose **Edit & annotate → Add link**, and drag a box over
any content. Choose **Website or file URL** for an `http://`, `https://`, or
`file://` address, or **Page in this PDF** for an internal page jump. Add an
optional description and save the link. Choose **Save as → PDF** to download the
clickable PDF; the blue editing outlines do not appear in the export.

Select a box to edit, move, resize, follow, or delete its link. Undo/Redo is
available. Double-click a box to edit it. For keyboard insertion, choose Add link
and press Enter, then position the saved box using arrow keys. Escape cancels.
Reopening the saved PDF restores supported links as editable boxes.

Internal links follow their destination when pages are reordered. If a destination
page is deleted, edit or delete the affected link, or undo the page deletion,
before exporting. Extracted PDFs omit links to pages outside the extraction.
Local `file://` links require the file on the reader's device or network and
permission from their PDF viewer; shared web files should use HTTPS sharing URLs.
Image and sanitized exports do not preserve clickable links.
