# Changelog

All notable changes to TCEA MediaMkr are documented here. This project uses
its own independent version numbers.

## [Unreleased]

### Added
- Project foundation: repository structure, shared TCEA navy-and-gold theme
  (`assets/css`), navigation, and homepage i18n engine (English + Spanish).
- Branded homepage with searchable, category-filtered grid of eleven tools.
- Branded placeholder pages for all eleven applications.
- Legal and policy docs: `LICENSE` (AGPL-3.0-or-later), `NOTICE.md`,
  `THIRD_PARTY_LICENSES.md`, `PRIVACY.md`, `ACCESSIBILITY.md`.
- Validation scripts and CI scaffolding.

### Planned
- Migrate the eleven tools in phases: CodeMkr, MemeMkr, PuzzleMkr; then
  PlotMkr, PixelMkr, BGMkr; then GIFMkr, DocMkr; then AudioMkr; then FormatMkr
  and ClipMkr.
