# PuzzleMkr Library

Ready-to-use classroom puzzle packs for PuzzleMkr, part of TCEA MediaMkr.

Each `.json` file is a puzzle setup (image reference plus questions and
answers). Open a pack from the library page, or import a `.json`, `.csv`, or
`.xlsx` file into PuzzleMkr. Bilingual packs include English and Spanish text.

Everything runs locally in the browser. No student accounts or data collection.
